Registro e inicio de sesión

Crear una cuenta

Registra tu nombre completo, correo electrónico y una contraseña segura.

Iniciar sesión

03 — TAREAS

Gestión de tareas

Organiza tus actividades diarias y lleva un control de las tareas pendientes y completadas.

Agregar tarea

Presiona el botón "+" y completa el nombre, descripción y fecha de vencimiento.

Completar

Utiliza el botón de check verde para mover una tarea a la sección de completadas.

Eliminar

Utiliza el icono de papelera para eliminar una tarea que ya no necesites.

Restaurar

Las tareas completadas pueden restaurarse para volver a trabajar en ellas.

Campos de una nueva tarea:
Nombre de la tarea · Descripción · Fecha de vencimiento
04 — FINANZAS

Control de ahorros y finanzas

Utiliza MyProfile como un libro contable personal para registrar ingresos y gastos.

Ingresos

Registra un ingreso indicando el monto y descripción. El valor se suma al saldo.

Gastos

Registra tus gastos para descontarlos automáticamente del saldo disponible.

Histórico

Consulta cronológicamente tus movimientos financieros registrados.

05 — SEGURIDAD

Bóveda de contraseñas

Mantén organizadas tus credenciales de acceso a plataformas y servicios web.

Búsqueda rápida

Utiliza la barra de búsqueda para localizar rápidamente una plataforma registrada.

Nueva credencial

Presiona "+" y registra sitio web, usuario o cuenta y clave.

Almacenamiento

El manual indica que la información se almacena cifrada en la nube.

Campos necesarios: Sitio Web / Plataforma · Usuario / Cuenta · Clave
06 — BIENESTAR

Salud y bienestar

El módulo de salud ayuda a controlar la hidratación y los descansos visuales durante el uso de dispositivos.

Hidratación

La meta diaria establecida es de 8 vasos de agua. Cada vaso registrado actualiza el progreso.

Descanso visual

Después de 20 minutos de uso continuo, la aplicación recomienda realizar una pausa.

Pausa de 5 minutos

El manual indica una recomendación de descanso visual de 5 minutos.

Funcionamiento del temporizador:
El conteo se pausa cuando la pantalla del teléfono se apaga o bloquea. Al finalizar el descanso, la aplicación notifica que puedes continuar.
