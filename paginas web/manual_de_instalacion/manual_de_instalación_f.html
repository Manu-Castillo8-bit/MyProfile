// antes de empezar

Requisitos del sistema

Para la correcta instalación de la app MyProfile, el dispositivo o equipo debe cumplir con las siguientes especificaciones mínimas.

{ }android.json
  • sistemaOperativo:"Android 5.0 (Lollipop / API nivel 21) o superior"
  • arquitectura:"ARM 32/64 bits (ARM64) y x86/x86_64"
  • memoriaRAM:"2 GB mínimo recomendado"
  • formatoArchivo:".APK"
{ }windows.json
  • sistemaOperativo:"Windows 10 (v1809+) o Windows 11"
  • arquitectura:"x86, x64 o ARM64"
  • memoriaRAM:"4 GB mínimo, 8 GB recomendado"
  • formatoArchivo:".EXE / .MSI"

// instalación en computadora

Cómo instalar en PC (Windows)

Sigue estos pasos para llevar a cabo la instalación del programa en tu equipo con Windows.

01

Ejecutar el instalador

Abre la carpeta de descargas o la carpeta Installer y haz doble clic sobre el archivo ejecutable del instalador (.exe).

pc-paso1.png
02

Conceder permisos de administrador

Acepta el mensaje del Control de Cuentas de Usuario (UAC) para otorgar los permisos de instalación necesarios en el sistema.

pc-paso2.png
03

Elegir idioma y aceptar términos

Selecciona el idioma de tu preferencia para el asistente de instalación y acepta los términos del acuerdo de licencia.

pc-paso3.png
04

Confirmar carpeta de destino

Selecciona la ruta de instalación donde se almacenarán los archivos del programa o mantén la carpeta predeterminada.

pc-paso4.png
05

Iniciar proceso de instalación

Haz clic en el botón Instalar y espera a que la barra de progreso complete la extracción de archivos.

pc-paso5.png
06

Finalizar e iniciar la aplicación

Haz clic en Finalizar. Marca la casilla para abrir el programa automáticamente y comprobar su funcionamiento.

pc-paso6.png

// instalación en móvil

Cómo instalar en Android

Sigue estos pasos para instalar el paquete de la aplicación (.apk) en tu dispositivo móvil Android.

01

Descargar el archivo APK

Descarga el paquete de instalación .apk en tu teléfono desde el enlace proporcionado o transfiérelo a la memoria del dispositivo.

android-paso1.png
02

Permitir orígenes desconocidos

Si es la primera vez que instalas una app fuera de Google Play, ve a Ajustes > Seguridad (o activa la opción desde el navegador/administrador de archivos) para autorizar la instalación de fuentes desconocidas.

android-paso2.png
03

Abrir el archivo APK

Abre el administrador de archivos de tu teléfono, dirígete a la carpeta Descargas y pulsa sobre el archivo .apk.

android-paso3.png
04

Confirmar la instalación

Aparecerá un mensaje emergente solicitando la confirmación. Pulsa sobre la opción Instalar.

android-paso4.png
05

Abrir la aplicación

Una vez completado el proceso, presiona Abrir para iniciar la aplicación MyProfile en tu dispositivo Android.

android-paso5.png
