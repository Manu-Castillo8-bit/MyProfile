01 · ANTES DE EMPEZAR

Requisitos del sistema

Para la correcta compilación, ejecución y despliegue de MyProfile, el entorno de desarrollo debe cumplir estas especificaciones mínimas.

HARDWARE RECOMENDADO

  • Procesador — Intel Core i5 / AMD Ryzen 5 (64 bits), 2.5 GHz o superior
  • RAM — 16 GB recomendado para .NET MAUI + emulador Android (mínimo 8 GB)
  • Almacenamiento — 25 GB libres, de preferencia en SSD

SOFTWARE REQUERIDO

  • SO — Windows 10 (21H2+) / Windows 11, 64 bits
  • IDE — Visual Studio 2022 (17.8+), Community/Professional/Enterprise
  • Framework — SDK de .NET 8.0 / .NET 9.0
  • Móvil — Android SDK (API 31+) con Hyper-V o HAXM habilitado

02 · CONFIGURACIÓN LOCAL

Dependencias y orden de instalación

Siga estrictamente este orden para evitar conflictos de dependencias en el entorno local.

1

Instalación de Visual Studio 2022

  • Descargue el instalador ejecutable desde la web oficial de Microsoft.
  • En Visual Studio Installer, seleccione la carga de trabajo obligatoria: Desarrollo de aplicaciones de interfaz de usuario de aplicaciones multiplataforma de .NET (.NET MAUI).
  • Verifique que los componentes opcionales Android SDK Setup y Emulador de Android permanezcan seleccionados.
2

Clonación u obtención del código fuente

Descargue y extraiga el paquete de código fuente de MyProfile en una ruta local limpia, sin espacios ni caracteres especiales — por ejemplo C:\Proyectos\MyProfile.

3

Restauración de paquetes NuGet

  • Abra la solución MyProfile.sln en Visual Studio 2022.
  • Clic derecho sobre la solución en el Explorador de Soluciones → Restaurar paquetes NuGet.
  • Paquetes clave instalados automáticamente: supabase-csharp, Postgrest, Realtime, Newtonsoft.Json y dependencias nativas de .NET MAUI.

03 · BACKEND

Configuración del backend en Supabase

MyProfile usa Supabase como backend en la nube respaldado por PostgreSQL. Cree el proyecto y ejecute el script DDL para construir el esquema relacional.

Creación del proyecto

Ingrese a la consola de Supabase, inicie sesión y cree un nuevo proyecto con el nombre MyProfile-DB.

Ejecución del script DDL

En SQL Editor, copie y ejecute el siguiente script unificado. Crea las tablas usuario, tarea, contrasenas, recordatorio_salud y movimiento_financiero, integradas con el módulo de autenticación nativo auth.users.

schema.sql 
-- 1. Tabla USUARIO (vinculada con Auth de Supabase)
CREATE TABLE usuario (
  id_usuario SERIAL PRIMARY KEY,
  nombre VARCHAR(100) NOT NULL,
  correo VARCHAR(150) UNIQUE NOT NULL,
  rol VARCHAR(50),
  fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  auth_user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE
);

-- 2. Tabla TAREA
CREATE TABLE tarea (
  id_tarea SERIAL PRIMARY KEY,
  id_usuario INT NOT NULL,
  titulo VARCHAR(150) NOT NULL,
  descripcion TEXT,
  fecha_vencimiento DATE,
  estado VARCHAR(50),
  CONSTRAINT fk_tarea_usuario FOREIGN KEY (id_usuario)
    REFERENCES usuario(id_usuario) ON DELETE CASCADE
);

-- 3. Tabla CONTRASENAS
CREATE TABLE contrasenas (
  id_contrasena SERIAL PRIMARY KEY,
  id_usuario INT NOT NULL,
  sitio_web VARCHAR(255),
  usuario_cuenta VARCHAR(100),
  clave_cifrada TEXT,
  CONSTRAINT fk_contrasena_usuario FOREIGN KEY (id_usuario)
    REFERENCES usuario(id_usuario) ON DELETE CASCADE
);

-- 4. Tabla RECORDATORIO_SALUD
CREATE TABLE recordatorio_salud (
  id_recordatorio SERIAL PRIMARY KEY,
  id_usuario INT NOT NULL,
  tipo_recordatorio VARCHAR(100),
  frecuencia_minutos INT,
  activo BOOLEAN DEFAULT TRUE,
  CONSTRAINT fk_recordatorio_usuario FOREIGN KEY (id_usuario)
    REFERENCES usuario(id_usuario) ON DELETE CASCADE
);

-- 5. Tabla MOVIMIENTO_FINANCIERO
CREATE TABLE movimiento_financiero (
  id_movimiento SERIAL PRIMARY KEY,
  id_usuario INT NOT NULL,
  monto NUMERIC(12, 2) NOT NULL,
  tipo VARCHAR(50),
  descripcion TEXT,
  fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT fk_movimiento_usuario FOREIGN KEY (id_usuario)
    REFERENCES usuario(id_usuario) ON DELETE CASCADE
);
RLS
Verifique en Table Editor que las cinco tablas tengan habilitado Row Level Security, para asegurar que cada fila sea visible únicamente para su id_usuario correspondiente.

04 · CLIENTE MÓVIL

Configuración del proyecto y cadenas de conexión

Con el backend listo, enlace la aplicación móvil cliente con su instancia remota de Supabase.

Obtención de claves de acceso

En el panel de Supabase, vaya a Project Settings → API y copie el Project URL (por ejemplo https://xyz.supabase.co) y la clave pública anon key.

Vinculación en la aplicación (.NET MAUI)

Dentro de Visual Studio, ubique el archivo de configuración del servicio — por ejemplo Services/SupabaseService.cs o Constants.cs — y reemplace los valores predeterminados por las credenciales de su proyecto:

Constants.cs 
public static class Constants
{
    public const string SupabaseUrl = "https://TU_PROYECTO.supabase.co";
    public const string SupabaseKey = "TU_CLAVE_ANON_PUBLIC_KEY";
}

Guarde todos los cambios en la solución.

05 · PUESTA EN MARCHA

Compilación, despliegue y credenciales de prueba

Procedimiento de despliegue

1

En la barra de herramientas superior de Visual Studio, seleccione la configuración de compilación Debug o Release.

2

En el menú de dispositivos objetivo, seleccione el emulador de Android (por ejemplo Pixel 5 — API 33) o un dispositivo físico conectado por depuración USB.

3

Presione F5 o el botón verde de Iniciar para ejecutar el proceso de Build & Deploy.

4

Espere a que la aplicación abra automáticamente en el emulador, mostrando la vista de Login / Dashboard.

06 · TROUBLESHOOTING

Solución de errores frecuentes

Error / SíntomaCausa probableSolución recomendada
Error de conexión a la API de Supabase SupabaseUrl o SupabaseKey incorrectas, o falta de conexión a internet. Revise que la URL y la Anon Key en Constants.cs no tengan espacios extra. Verifique conexión a internet activa.
Error en FK o restricción de id_usuario Se intenta guardar un registro (tarea, movimiento_financiero) sin haber registrado antes la fila en la tabla usuario. Asegúrese de que el flujo de Login/Registro guarde primero el perfil en la tabla usuario, obteniendo el auth_user_id de Supabase.
El emulador de Android no enciende Falta de virtualización habilitada en el procesador. Ingrese a la BIOS/UEFI y habilite Intel VT-x o AMD-V. En Windows, active la característica Plataforma de hipervisor de Windows.
Error de mapeo JSON / C# Incompatibilidad de nombres entre columnas SQL y modelos en .NET MAUI. Verifique que las propiedades de los modelos C# usen [Column("nombre_columna")], respetando la nomenclatura en minúsculas de PostgreSQL (ej. id_usuario, clave_cifrada).
