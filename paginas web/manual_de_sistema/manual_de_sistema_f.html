PROPÓSITO DEL SISTEMA

Un solo lugar para administrar tu vida diaria.

En la actualidad, las personas utilizan múltiples aplicaciones dispersas para gestionar su día a día. MyProfile resuelve la necesidad de centralizar la gestión personal, financiera, de seguridad y de salud en una única plataforma móvil unificada.

Está dirigido a usuarios jóvenes y adultos que buscan optimizar su productividad y bienestar general, permitiéndoles administrar sus actividades diarias, salvaguardar credenciales importantes y recibir asistencia automatizada para rutinas de salud básicas.

Arquitectura Tecnológica

El sistema MyProfile ha sido desarrollado bajo los siguientes estándares tecnológicos por el equipo de Nexo:

Frontend / Interfaz de Usuario

Construido con .NET MAUI utilizando C# y XAML. La navegación principal está orquestada mediante la arquitectura AppShell (Bottom Navigation Bar) aplicando una paleta de colores moderna centrada en el "Dark Mode" (Modo Oscuro).

Backend / Persistencia de Datos

Utiliza una infraestructura en la nube respaldada por Supabase (Backend as a Service). La información se almacena de forma estructurada y segura en una base de datos relacional remota (PostgreSQL), lo que permite la gestión y sincronización de datos en tiempo real.

Módulos del Sistema y Funcionalidades

El sistema está dividido en cinco módulos principales, accesibles de manera directa a través de la barra de navegación inferior:

Dashboard

Panel de Inicio

Panel de control principal que actúa como resumen visual. Integra métricas clave extraídas dinámicamente de los demás módulos, permitiendo al usuario conocer su saldo disponible, estado de tareas y avance de hidratación de un solo vistazo.

Módulo de Tareas

Ciclo de Vida de Actividades

Gestor del ciclo de vida de las actividades personales.

Nueva Tarea

Formulario accesible mediante el botón de la parte superior derecha para registrar título (ej. "Hacer limpieza"), descripción opcional (ej. "Limpiar habitación antes de salir") y fecha de vencimiento.

Tareas Pendientes

Listado interactivo de tareas activas. Permite marcar cualquier elemento como completado (trasladándolo al histórico) o eliminarlo de manera directa.

Tareas Completadas

Historial de actividades finalizadas, contando con la función de restauración para trasladar la tarea nuevamente a la lista de pendientes si el usuario lo requiere.

Módulo de Ahorro

Gestión Financiera Personal

Herramienta de gestión financiera personal y control de flujo de caja.

Visualización de Saldo

Tarjeta principal que muestra el capital neto calculado automáticamente.

Registro de Movimientos

Interfaz con campo de monto y descripción, junto con los botones de acción "+ Ingreso" (para sumar capital) y "- Gasto" (para aplicar deducciones).

Historial

Sección de "Últimas transacciones" que lista cronológicamente las entradas y salidas de dinero asociadas a la cuenta.

Módulo de Contraseñas

Bóveda Privada de Credenciales

Bóveda privada de credenciales.

Buscador en Tiempo Real

Barra superior con texto de ayuda ("Buscar credencial...") para filtrar instantáneamente las cuentas guardadas según el usuario escribe.

Formulario de Nueva Credencial

Ventana flotante emergente para ingresar el Sitio web/Plataforma, el Usuario/Cuenta y la Clave secreta, con botones para Guardar o Cancelar la operación.

Listado Principal

Muestra las credenciales almacenadas o en su defecto un estado descriptivo en pantalla cuando no hay datos registrados.

Módulo de Salud

Bienestar y Hábitos Saludables

Asistente de bienestar y hábitos saludables.

Control de Hidratación

Monitoreo de meta diaria de 8 vasos de agua. Un botón dedicado permite "agregar vaso", actualizando al instante el indicador visual y la barra de progreso reflejada en el Dashboard.

Descanso Visual

Herramienta opcional que contabiliza el uso del teléfono. Tras 20 minutos continuos de pantalla activa, el sistema emite una notificación recomendando un descanso visual de 5 minutos, notificando al usuario una vez concluido el lapso.

Roles de Usuario

Debido a la naturaleza de gestión estrictamente personal de MyProfile, el sistema opera bajo una estructura de rol único (Single-Tenant o inquilino único):

Usuario Propietario (Owner)

Tiene acceso incondicional y permisos totales sobre su cuenta e información. Es el único perfil autorizado para ejecutar operaciones de Lectura, Escritura, Actualización y Eliminación (CRUD) sobre sus tareas, registros financieros, hábitos de salud y bóveda de contraseñas almacenados en el backend de Supabase.

Reglas de Negocio

El sistema aplica internamente las siguientes reglas lógicas para garantizar la coherencia de la información y una experiencia de usuario óptima:

Cálculo Financiero Automatizado

El "Saldo actual" en el módulo de Ahorros no es editable en forma directa; es el resultado de la fórmula estricta: (Sumatoria de Ingresos) − (Sumatoria de Gastos).

Transición Exclusiva de Estados

Un registro de tarea sólo puede pertenecer al estado "Pendiente" o "Completado", previniendo duplicidades entre listas.

Manejo de Estados Vacíos

En la bóveda de Contraseñas, cuando la base de datos no retorne registros para el usuario, el sistema despliega el mensaje contextual "No hay credenciales guardadas" en lugar de un error de carga.

Lógica de Conteo de Pantalla

El temporizador de descanso visual evalúa el uso continuo de la pantalla. Si el sistema operativo notifica que el dispositivo ha sido bloqueado o la pantalla apagada, el conteo se pausa inmediatamente para no consumir el tiempo de descanso.

Requerimientos Funcionales Cubiertos

Durante la fase de construcción del software, el equipo de Nexo cumplió los requerimientos estipulados en la Especificación de Requerimientos de Software (ERS):

ID Descripción del Requerimiento Funcional
RF-01 El sistema debe permitir al usuario registrar una nueva tarea, incluyendo título, descripción y fecha de vencimiento.
RF-02 El sistema debe permitir marcar las tareas como "pendientes" o "completadas", y visualizar un listado organizado de las mismas.
RF-03 El sistema debe permitir eliminar tareas que ya no se realizaran.
RF-04 El sistema debe permitir registrar, editar y eliminar contraseñas y cuentas (red social o sitio web, usuario, clave).
RF-05 El sistema debe permitir ingresar montos de ingresos o gastos para llevar un control real de los ahorros.
RF-06 El sistema debe permitir agregar una descripción de las transacciones que se realizan para que el usuario este informado de lo que ha sucedido en los últimos días.
RF-07 El sistema debe tener un espacio de recordatorio de hidratación para cuidar tu salud.
RF-08 El sistema debe tener un apartado donde si el usuario utliza la computadora o el teléfono pueda activar la opción de recordatorio de un descanso visual de 5 minutos cada 20 minutos.
RF-09 El sistema debe mostrar un resumen general (dashboard) consolidando las tareas activas, el saldo del ahorro y los accesos rápidos a cuentas, y en recordatorio de cuando debes beber tu proximo vaso de agua.
RF-10 El sistema debe enviar recordatorios de las tareas pendientes, de tomar agua y descanso visual en notificación emergente o por correo electrónico.

Limitaciones Actuales y Mejoras Futuras

Limitaciones Actuales

  • Dado que la persistencia se gestiona centralizadamente en la nube mediante Supabase, la aplicación requiere una conexión a internet activa para sincronizar de manera inmediata las operaciones de los módulos.
  • El envío de alertas y notificaciones del módulo de Salud depende de los permisos otorgados por el usuario a nivel del sistema operativo.

Mejoras Futuras

  • Autenticación Biométrica: Implementar validación por huella dactilar o reconocimiento facial (FaceID) como requisito previo para abrir y consultar las credenciales en el Módulo de Contraseñas.
  • Modo Offline con Sincronización Postergada: Desarrollar un almacenamiento en caché local para permitir el registro de transacciones o tareas sin acceso a internet, sincronizando los cambios con Supabase en cuanto se reestablezca la conectividad.
