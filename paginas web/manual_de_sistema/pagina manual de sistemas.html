ARQUITECTURA

Cómo está construido

El sistema separa con claridad la capa visual de la capa de datos, comunicándose en tiempo real con la nube.

Frontend

Construido con .NET MAUI en C# y XAML. La navegación entre módulos se orquesta con AppShell, mostrado como una barra de navegación inferior, sobre una paleta centrada en modo oscuro.

Backend

Supabase actúa como Backend as a Service sobre una base de datos relacional PostgreSQL, sincronizando en tiempo real la información de cada módulo.

MÓDULOS

Cinco módulos, una barra de navegación

Cada módulo se abre directamente desde la barra inferior. El Dashboard resume lo que ocurre en los otros cuatro.

Dashboard

Panel de inicio

Resumen visual que integra métricas de los demás módulos: saldo disponible, estado de tareas y avance de hidratación, todo de un solo vistazo.

Tareas

Ciclo de vida de actividades
Nueva tarea

Formulario con título, descripción opcional y fecha de vencimiento, accesible desde el botón superior derecho.

Pendientes

Listado interactivo donde cada tarea puede marcarse como completada o eliminarse directamente.

Completadas

Historial de tareas finalizadas, con opción de restaurarlas a la lista de pendientes cuando sea necesario.

Ahorro

Flujo de caja personal
Saldo

Tarjeta principal con el capital neto, calculado automáticamente a partir de los movimientos registrados.

Registro de movimientos

Campo de monto y descripción, con botones "+ Ingreso" para sumar capital y "- Gasto" para aplicar deducciones.

Historial

"Últimas transacciones" lista de forma cronológica las entradas y salidas asociadas a la cuenta.

Contraseñas

Bóveda privada
Buscador en tiempo real

Barra superior que filtra las credenciales guardadas al instante mientras el usuario escribe.

Nueva credencial

Ventana emergente para registrar sitio o plataforma, usuario/cuenta y clave secreta, con opción de guardar o cancelar.

Listado

Muestra las credenciales almacenadas, o un estado descriptivo cuando la bóveda está vacía.

Salud

Bienestar y hábitos
Hidratación

Monitorea una meta diaria de 8 vasos de agua. El botón "agregar vaso" actualiza al instante el indicador y la barra de progreso del Dashboard.

Descanso visual

Contabiliza el uso continuo del teléfono. Tras 20 minutos de pantalla activa, notifica un descanso de 5 minutos y avisa al concluir.

ROLES

Un solo rol, control total

MyProfile opera bajo una arquitectura single-tenant: no hay equipos ni cuentas compartidas.

Owner

Acceso incondicional y permisos totales sobre su cuenta. Es el único perfil autorizado para leer, escribir, actualizar y eliminar (CRUD) sus tareas, registros financieros, hábitos de salud y credenciales en Supabase.

REGLAS

Lógica de negocio

Cálculo financiero

El saldo del módulo de Ahorro no se edita directamente: siempre es (suma de ingresos) − (suma de gastos).

Estados de tarea

Una tarea sólo puede estar en "Pendiente" o "Completado", nunca en ambas listas a la vez.

Bóveda vacía

Si no hay credenciales guardadas, se muestra el mensaje "No hay credenciales guardadas" en vez de un error de carga.

Conteo de pantalla

El temporizador de descanso visual se pausa de inmediato si el sistema operativo bloquea o apaga la pantalla.

ERS

Requerimientos cubiertos

REQ-UI-01

Diseño moderno con bordes redondeados y soporte completo para modo oscuro.

REQ-NAV-01

Navegación fluida entre módulos mediante el patrón AppShell de .NET MAUI.

REQ-VAL-01

Validación de formularios en tareas, transacciones y credenciales para evitar datos nulos o vacíos.

REQ-BACK-01

Backend centralizado en la nube con Supabase que garantiza la persistencia remota de los datos.

ROADMAP

Limitaciones y mejoras futuras

Limitaciones actuales

  • Requiere conexión a internet activa: la persistencia vive en Supabase y las operaciones se sincronizan de inmediato.
  • Las alertas del módulo de Salud dependen de los permisos de notificación otorgados por el sistema operativo.

Mejoras futuras

  • Autenticación biométrica (huella o FaceID) como requisito para abrir el módulo de Contraseñas.
  • Modo offline con caché local, sincronizando con Supabase en cuanto vuelva la conectividad.
