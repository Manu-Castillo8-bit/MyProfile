Actualización
1.1

MyProfile incorpora nuevas funciones y mejoras orientadas a proporcionar una experiencia más clara, estable y funcional.

Nueva identidad

Logo para identificar fácilmente la aplicación.

Pantalla de carga

Información breve sobre las funciones de la aplicación.

Acceso persistente

La sesión puede mantenerse activa en el dispositivo.

Más interacción

Nuevas animaciones para los botones principales.

Lo que cambió

Diseñada para funcionar mejor.

Cada actualización responde a una necesidad específica dentro de la experiencia de uso de MyProfile.

01 · IDENTIDAD

Logo de inicio

Se implementó un logo y el nombre MyProfile para facilitar la identificación de la aplicación dentro del dispositivo.

02 · INICIO

Pantalla informativa

Al iniciar la aplicación se muestra información breve sobre el programa y las funciones disponibles.

03 · SEGURIDAD

Contraseña simplificada

Se eliminó una de las opciones para visualizar la contraseña y se mantiene el botón visual del ojo.

04 · SESIÓN

Sesión persistente

La aplicación detecta que el usuario ya inició sesión anteriormente en el dispositivo.

05 · INTERFAZ

Botones animados

Se agregaron animaciones a los botones de preferencias, ingresos, gastos y credenciales.

06 · PROPÓSITO

¿Qué hace MyProfile?

Se agregó una pantalla donde se explica el propósito y funcionamiento de la aplicación.

07 · SALUD

Descanso visual

Ahora se puede avisar que la pantalla será suspendida en un minuto y permitir cancelar o ejecutar la acción.

08 · FINANZAS

Editar movimientos

El historial financiero permite editar el monto y la descripción de una transacción registrada.

09 · ESTABILIDAD

Interfaz estable

Se mejoró el funcionamiento para mantener la aplicación dentro de su interfaz principal.

10 · DATOS

Sincronización

Se incorporó la actualización de datos para facilitar la sincronización entre dispositivos conectados.

Evolución

De una versión a una experiencia mejor.

Las mejoras de MyProfile 1.1 transforman diferentes aspectos de la aplicación.

Identidad visual

La aplicación ahora cuenta con una identificación visual propia.

Inicio más informativo

Se añadió una pantalla de carga con información sobre el programa.

Acceso mejorado

La sesión puede mantenerse activa en el dispositivo donde fue iniciada.

Bienestar

El descanso visual ahora cuenta con una acción de suspensión de pantalla.

Control financiero

Los movimientos financieros pueden editarse además de eliminarse.

Datos actualizados

La actualización de datos facilita la sincronización de información entre dispositivos.
